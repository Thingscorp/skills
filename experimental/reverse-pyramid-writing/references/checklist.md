# Reverse Pyramid Gate

Run every check on the finished draft. Any failure sends the draft
back to the named step. Do not soften a failure into a note.

## Structure (Step 3)

- [ ] Read only layer 1. It states the outcome, completely, with no
      dependence on anything below it.
- [ ] Delete the last layer. The piece still reads complete.
- [ ] Each layer is more detailed and less essential than the one
      above it. No layer reverses that order.
- [ ] No fact appears for the first time in a layer below the first
      decision or step that depends on it.
- [ ] Every procedure states its prerequisites before its first
      instruction, and its expected outcome at each major step.

## Scope (Step 2)

- [ ] Zero quoted speech.
- [ ] Zero opinions, verdicts, or takeaways stated as the writer's own.
- [ ] Zero project, company, or brand names, unless the task explicitly
      required one.
- [ ] Every paragraph is about a feature, a function, or a user
      benefit.

## Language (Step 4)

- [ ] Instructions and procedures address the reader as "you".
- [ ] Sentences are active voice, except where the actor is genuinely
      unknown, and that exception is rare.
- [ ] Current states use present tense. Outcomes use future tense.
      No sentence mixes the two for the same fact.
- [ ] Every technical term is defined at first use, and the same term
      names the same concept throughout.
- [ ] Zero em dashes.

## Redundancy (Step 5)

- [ ] Search the draft for each core concept. It has exactly one
      definitive explanation; every other mention is a reference or a
      use, not a restatement.
- [ ] Zero generic transitions: no sentence exists only to announce,
      summarize, or bridge.
- [ ] For every paragraph, name what it adds: a unique perspective,
      an implementation-specific detail, or essential context for its
      layer. A paragraph with no answer is cut.
