# Contributing

- Run the eval before and after: `npm install && npm test`. All 7 checks must pass.
- Every new claim in the README or references needs a backing check in `eval/eval.mjs`. Claims without checks do not merge.
- Example colors are generated by the scripts, never hand-picked.
- Keep the engine a dependency. Do not vendor `material-color-utilities` into the tree.
- Prose style: plain terms first, no em-dashes.
- The skill file `SKILL.md` and the references are the product. Changes there get the same review weight as code.
